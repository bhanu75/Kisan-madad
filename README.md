# 🌾 Kisan Madad - Digital Agriculture Platform

A comprehensive digital platform for Indian farmers to manage crops, monitor soil health, get market prices, and receive agricultural guidance in Hindi.

## 🚀 Features

- **Dashboard**: Complete farm overview with key metrics
- **Crop Management**: Health monitoring and disease detection
- **Soil Analysis**: pH, moisture, and nutrient tracking
- **Market Prices**: Real-time crop price updates
- **Weather Alerts**: Irrigation scheduling and weather warnings
- **Image Upload**: Crop photo analysis for disease detection
- **Multi-language**: Full Hindi language support

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Deployment**: Vercel
- **Language**: Hindi + English
